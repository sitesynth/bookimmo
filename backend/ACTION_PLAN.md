# ImmoSlot -- Action Plan MVP (6 месяцев)

## Резюме проекта

ImmoSlot -- сервис быстрого поиска арендного жилья в Германии.
Клиент регистрируется, выбирает район, система автоматически записывает его на просмотры раньше других.
Работает в партнерстве с лицензированным Mietmakler (DE).
Техническая платформа зарегистрирована за пределами ЕС.

Разработка -- без найма программистов, полностью на vibe-coding (Claude Code Max x2).

2. Публикует квартиру в нашу систему (до или вместо публикации на IS24)
3. Наши клиенты получают доступ раньше рынка
4. Клиент заселяется -- делим комиссию с агентством (50/50)

Pitch для агентства:
"У нас 200 проверенных арендаторов с документами. Вы публикуете квартиру -- через 2 часа 10 заявок с полным пакетом. Без расходов на IS24, без 200 спам-заявок."

## Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Бан аккаунтов IS24 | Средняя | Высокое | Пул аккаунтов, residential IP, человеческие задержки, 5-10 запросов/день/аккаунт |
| Клиент не платит после заселения | Высокая | Среднее | Предоплата или подписка вместо success fee |
| Агентства не подключаются | Средняя | Среднее | Подключать только после значимого трафика, показать реальные метрики |
| Vibe-coding не справляется со сложностью | Низкая | Высокое | Claude Code покрывает 90% задач; точечный аутсорс для оставшихся 10% |
| GDPR-жалоба | Низкая | Высокое | Разделение юрисдикций, маклер отвечает за данные клиентов |
| Конкуренты копируют | Средняя | Среднее | Скорость + база агентств + данные = moat |
